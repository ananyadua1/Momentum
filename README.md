# IELTS Momentum Engine – Working Prototype

## Overview

This repository contains a **lightweight, interactive prototype** for the **IELTS Momentum Engine**, an engagement-focused solution designed to improve user consistency, motivation, and course completion during long IELTS preparation cycles.

The prototype demonstrates how daily micro-missions, visible progress, and momentum-based feedback can help users build sustainable preparation habits within limited time availability.

---

## Problem Context

IELTS learners often engage intensely only near their exam date. During long preparation periods, motivation fluctuates and progress feels invisible, leading to low engagement and incomplete preparation.

This prototype explores how **behavior-driven engagement**, rather than content-heavy interactions, can keep users consistently involved from the early stages of preparation.

---

## What This Prototype Demonstrates

The prototype simulates the **core engagement loop** of the IELTS Momentum Engine:

* Daily **micro-mission** assignment (10-minute task)
* Real-time **momentum level updates**
* Skill-level **progress visualization** (Speaking, Listening, Writing)
* **Weekly activity tracking**
* **Low-friction comeback flow** after missed days
* Instant feedback after task completion

This is a **conceptual prototype**, not a production build.

---

## Tech Stack

* **HTML** – Structure
* **CSS** – Visual styling
* **JavaScript** – Interaction and state updates

---

## How to Run the Prototype

1. Clone or download this repository
2. Open `prototype.html` in any modern web browser
3. Interact with the page by:

   * Clicking **Start Now**
   * Completing a micro-mission
   * Observing progress and momentum updates

The prototype is optimized for **mobile viewport sizes**.
